An invented passport spread for the Republic of Veskar, a small North Atlantic island republic of fishermen, lighthouses and seabird sanctuaries. Left page: the data page of EINAR KETILSSON, issued 14 JAN 2026 in Havnvik, expiring 14 JAN 2036, with a machine-readable strip. Right page: six stamps tracing one trip — Havnvik to Bergen to Reykjavik and home, 21 JAN to 09 FEB 2026 — plus a LIGHTHOUSE DUES fee stamp and a Skarholm bird-sanctuary condition.

## Run it

```sh
node main.ts
```

It writes the spread to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`), the same bytes on every run.
